P.S. MANIKPUR ANDROID APP – SOURCE PROJECT (DEMO)

महत्वपूर्ण:
यह Android Studio source project है, तैयार APK नहीं। इस environment में Android SDK/Gradle build tools उपलब्ध नहीं थे, इसलिए यहाँ APK compile नहीं हो सका।

बनाने के चरण:
1. कंप्यूटर पर Android Studio इंस्टॉल करें।
2. इस ZIP को Extract करें।
3. Android Studio में इस folder को Open करें।
4. Gradle sync पूरा होने दें और जरूरत पड़ने पर Android SDK 35 डाउनलोड करें।
5. Build > Build Bundle(s) / APK(s) > Build APK(s) चुनें।
6. APK app/build/outputs/apk/debug/app-debug.apk में बनेगा।

इस वर्जन की सीमाएँ:
- यह offline demo/prototype है।
- असली user authentication/passwords नहीं हैं।
- Student database, cloud sync, official attendance और real exam records नहीं हैं।
- Notices और homework का demo data केवल app चलने तक local screen पर रहता है।
- तीन admin नाम demo में दिखते हैं: Ankush, Jitendra Singh, Madhav Yadav।
- वास्तविक बच्चों का नाम, फोन, पता, फोटो या marks इसमें न डालें जब तक स्कूल उचित सुरक्षा और अभिभावक की अनुमति की व्यवस्था न कर ले।
